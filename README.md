# GoSocial REST API

GoSocial is a RESTful API built with Go, Gin, and MongoDB that enables user registration, authentication, and post management.
It serves as the backend for a simple social media platform where users can create, view, and manage posts.

---

## Features
- User registration & login.
- Create, Read, Update, Delete posts.
- Fetch all posts.

---

## Tech Stack
- Language: Go
- Framework: Gin
- Database: MongoDB
- Authentication: JWT
- Testing: Postman

---

## Getting Started

**1. Clone the repository:**
```bash
git clone https://github.com/<your-username>/go-social-rest-api.git
```
**2. Navigate into the project folder:**
```bash
cd go-social-rest-api.git
```
**3. Install dependencies:**
```bash
go mod tidy
```
**4. Start the server:**
```bash
go run main.go
```
**Or**
```bash
go run .
```
